## 🛠️ Архитектура и Спецификация Системы

Данный проект представляет собой интеллектуального бота-органайзера, эмулирующего интерфейсы популярных мессенджеров (Telegram/WhatsApp) и реализующего продвинутые нативные Web API для управления асинхронными потоками данных и аппаратными ресурсами.

### 🚀 Реализованный функционал:

#### 📋 Обязательные функции (100% выполнение):
1. **История сообщений и ссылок:** Текстовые сообщения сохраняются в памяти. Ссылки (`http://` / `https://`) автоматически парсятся через регулярные выражения и превращаются в кликабельные элементы.
2. **Мультимедийные вложения:** Поддержка загрузки изображений, видео и аудио файлов как через классическую кнопку-клип (`📎`), так и через интерактивную зону **Drag & Drop** на всю панель.
3. **Скачивание файлов:** В каждый медиа-глоб встроена нативная кнопка для прямой загрузки вложения на ПК пользователя.
4. **Lazy Loading (Ленивая подгрузка):** Сообщения подгружаются с сервера порциями по 10 штук. При достижении scroll-вылета вверх, клиент запрашивает следующий пагинированный чанк.

#### 🌟 Дополнительные функции (Революционный UX/UI):
1. **Pinned Message:** Магнитная верхняя панель для фиксации важной публикации с аудитом в чате.
2. **Встроенные плееры HTML5:** Аудио и видео проигрываются прямо внутри बबल-карточек чата.
3. **Интерактивный ИИ-Бот (`@chaos`):** Парсер команд. При вводе `@chaos: joke`, `time`, `weather` или `help`, бот возвращает анимированные асинхронные ответы.
4. **Смена элементов управления (UX WhatsApp):** Микрофон записи (`🎤`) автоматически исчезает при вводе хотя бы одного символа в поле ввода, уступая место зеленому треугольнику отправки (`▶️`).
5. **Эргономичное всплывающее меню эмодзи:** Полноценный грид-выборщик смайликов, открывающийся по кнопке `😀` без сторонних библиотек.
6. **Контур безопасности записи:** Полная блокировка и скрытие кнопок аттачментов во время активной записи аудио с микрофона.
7. **Интеллектуальное зеркало действий (Anti-Collision):** Панель действий (`🗑️` удаление и `📌` пин) выводится слева для исходящих сообщений пользователя и справа для входящих от бота, исключая дев-ошибки вылета за границы контейнера.
8. **Фоновые напоминания (Notification API):** Кастомный парсер команды `@schedule: ЧЧ:ММ ДД.ММ.ГГГГ Текст`. Рассчитывает таймстамп на клиенте и запускает фоновый процесс, который выводит системное уведомление Windows/macOS даже при свернутом браузере. Текст и кавычки полностью опциональны.

## 🚀 Инструкция по локальному запуску

```bash
# 1. Запуск сервера (REST + WebSockets)
cd backend
npm install
npm start

# 2. Запуск сборщика фронтенда (Webpack 5)
cd frontend
npm install
npm start
```
